# 📰 Notícias Cidade

Site de notícias desenvolvido como projeto prático durante o curso **[Domine Web - 20 Cursos - HTML5, CSS3, SASS, Bootstrap 5, JS, ES6, PHP, OO, MySQL, JQuery, MVC, APIs, GIT e muito mais](https://www.udemy.com/course/web-completo/)**, do instrutor **Jamilton Damasceno**, na Udemy oferecido no treinamento do meu estágio pela Yankton Technologies.

O objetivo do projeto foi aplicar conceitos de estruturação semântica em HTML e estilização em CSS puro (sem frameworks), construindo um portal de notícias com múltiplas páginas e diferentes layouts de coluna.

## ✨ Funcionalidades

- Layout responsivo com estrutura de **1, 2 e 3 colunas**, dependendo da página
- Menu de navegação estilizado, com destaque visual da página ativa
- Página inicial com destaque, notícias recentes e última entrevista
- Páginas de categoria (Brasil, Internacional)
- Página de fotos com layout de coluna única
- Página de notícia individual (Nova Legislação)
- Seção lateral com lista de entrevistados
- Formulário de cadastro para newsletter
- Rodapé fixo com informações de copyright

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox/Float para estrutura de colunas, seletores por classe e id, pseudo-classes)

## 🚀 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/seu-usuario/noticias-cidade.git
   ```
2. Abra a pasta no VS Code (ou editor de sua preferência)
3. Abra o arquivo `index.html` no navegador (recomendado: usar a extensão **Live Server** do VS Code para recarregamento automático)
